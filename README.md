# Description
A Unity project built around disappearance, return, and the conflict between who we were and who we eventually become.
This repository explores the feeling of being gone long enough to be forgotten, and resurfacing with something new, something changed, something earned.

It's about being seen again, or so you think.
In reality, it's my last project, so I've decided to release my Magnum Opus my making a remaster of all my previous creations in one single game.
Each game will have the original concept, with the older ones getting their deserved upgrade, while keeping the story original, fresh and easy to understand.
In total there are 8 games, 7 from my previous, plus the newer addition: SEE ME AGAIN. The plot is really simple to understand: I will give a very unique and different way to play 
my games. I will give an example with the game that started all of this: King's Gambit. The new story features the story of the Devil's Checkmate, in a completely
new way to imagine the story. Before I even added the chess engine (aka the Holy Hell engine) I always wanted to add the full story, but didn't had the chance. <br>Trust the process.
